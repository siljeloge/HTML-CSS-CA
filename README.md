During my first semester at Noroff, I had to put together everything i've learned about UI/UX design, HTML and CSS to create a webpage. 
During my design-course, I could chose between 3 different sites to build, and I choose a webshop about jackets called "Rainy Days". So for this course, I had to code what i've designed.

<h1>Description</h1>
This was a project based on our design-project where I had already designed the website in Figma. So it was only to code with HTML and CSS. I made some minor changes from the original
design, but all in all it was the same design from Design 1. I started with the HTML, adding all the files and basic structure like header, footer and then added the contents for each page. 
When I was done, I started on the CSS. After I was done with the desktop, I added several media queries so it would be more responsive and look good on different screen-sizes. 
The page includes:

- Contactform
  
- Thumbnail with products
  
- Checkoutform
  
- Success-page

<h1>Built with</h1>

- Figma

- Basic HTML

- Basic CSS

<h1>Getting started</h1>

1. Clone the repo:
```bash
git clone git@github.com:siljeloge/HTML-CSS-CA.git
```

2. Install the dependencies:
```
npm install
```

<h1>Running</h1>

To run the app, run the following commands:

```bash
npm run start
```
